# 수식노트 (독립 웹앱)

수식이 포함된 마크다운(`.md`)을 **태블릿·휴대폰**에서 바로 편집하고, 인쇄하거나 PDF로 내보낼 수 있는 독립형 웹앱입니다.

서버·빌드 과정이 전혀 없는 순수 HTML/CSS/JS 한 장짜리 앱이라 GitHub Pages 등 정적 호스팅에 그대로 올려 배포할 수 있습니다.

> 같은 저장소 그룹의 [`streamlit_util`](https://github.com/atom-02/streamlit_util) 저장소에도 "수식노트" 탭이 있습니다. 그쪽은 PC용 Streamlit 앱 안의 한 기능이고, 이 저장소는 **태블릿/휴대폰 화면에 최적화된 별도의 독립 배포판**입니다.

## 주요 기능

- **반응형 레이아웃**: 휴대폰·좁은 태블릿(세로)에서는 [에디터]/[미리보기] 탭 전환, 넓은 태블릿(가로)·PC에서는 좌우 분할 화면
- **터치 친화적 UI**: 버튼 터치 영역 44px 이상, 입력창 확대(줌) 방지용 폰트 크기
- **수식 렌더링**: [KaTeX](https://katex.org/) 사용, 인라인 수식은 `$...$`, 블록 수식은 `$$...$$`
- **마크다운 렌더링**: [markdown-it](https://github.com/markdown-it/markdown-it) 사용 (표, 목록, 굵게, 코드 등)
- **파일 열기/저장**: 기기에서 `.md` 파일 열기, 작성한 내용을 `.md` 파일로 저장
- **인쇄 / PDF로 저장**: 브라우저 기본 인쇄 기능을 사용 — 인쇄 대화상자에서 "PDF로 저장"을 선택하면 그대로 PDF 파일이 됩니다. 태블릿/휴대폰 브라우저(Chrome, Safari 등)에서도 동일하게 동작합니다.
- **자동 저장**: 브라우저 로컬 저장소(localStorage)에 입력 중인 내용을 자동 저장 — 새로고침해도 유지됩니다.
- **홈 화면에 추가 가능**: `manifest.json`을 포함하고 있어 태블릿/휴대폰 브라우저에서 "홈 화면에 추가"하면 앱처럼 아이콘으로 실행할 수 있습니다.
- **오프라인 친화적**: 수식/마크다운 라이브러리(KaTeX, markdown-it)를 외부 CDN이 아니라 이 저장소 안(`vendor/`)에 함께 담아 배포합니다. 학교 네트워크가 특정 CDN을 차단해도 렌더링이 깨지지 않고, 첫 로딩 이후에는 별도 서버 통신 없이 동작합니다.
- **문제 목록(문제 은행)**: 작성한 문제를 제목·태그와 함께 여러 개 저장하고, 검색·태그 필터로 찾아 다시 불러오거나 여러 개를 골라 한 번에 시험지로 합칠 수 있습니다 (자세한 사용법은 아래 참고).
- **정답 접기/펼치기(자기 채점용)**: 문제 안에 `<details><summary>정답 및 풀이 보기</summary>...</details>` 형태로 정답을 써두면, 학생이 스스로 풀어본 뒤 클릭해서 정답을 확인할 수 있습니다. "정답 모두 펼치기" 버튼으로 전체를 한 번에 펼치거나 접을 수 있고, 접힌 상태로 인쇄하면 정답이 빠진 학생용 시험지가, 펼친 상태로 인쇄하면 정답이 포함된 교사용 정답지가 됩니다.

## 파일 구조

```
susik-note-web/
├── index.html      # 앱 전체 (마크업 + 스타일 + 스크립트, 단일 파일)
├── manifest.json   # PWA 매니페스트 (홈 화면 추가용 메타데이터)
├── icon.svg        # 앱 아이콘
├── vendor/         # KaTeX·markdown-it 라이브러리 (CDN 대신 이 저장소에 직접 포함)
└── README.md
```

## 로컬에서 열어보기

별도 빌드 과정이 없으므로 `index.html`을 브라우저로 바로 열어도 되고, 정적 서버로 띄워도 됩니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## GitHub Pages로 배포하기

1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Source**를 `Deploy from a branch`로 설정합니다.
3. **Branch**를 `main` / `(root)`로 선택하고 저장합니다.
4. 잠시 후 `https://<계정명>.github.io/<저장소명>/` 주소로 배포됩니다.

## 사용 방법

1. 상단 입력창에 `.md` 저장 시 쓸 파일 이름을 입력합니다.
2. 왼쪽(또는 [에디터] 탭)에 마크다운을 작성합니다. 인라인 수식은 `$x^2$`, 블록 수식은 `$$x = \frac{-b}{2a}$$` 형태로 씁니다. 인쇄물의 제목은 별도 입력창 없이, 본문 맨 앞에 `# 제목` 형태로 직접 적으면 그대로 인쇄/PDF에 반영됩니다.
3. 오른쪽(또는 [미리보기] 탭)에서 렌더링된 결과를 바로 확인합니다.
4. **Markdown** 버튼으로 `.md` 파일을 저장하거나, **인쇄 / PDF** 버튼으로 인쇄·PDF 저장을 할 수 있습니다.

### 문제 목록(문제 은행) 사용법

1. 문제 하나를 작성한 뒤 상단의 **💾 문제로 저장** 버튼을 누르면, 제목(첫 줄 제목을 자동으로 채워줌)과 태그(쉼표로 구분, 예: `이차방정식, 난이도-하`)를 입력하고 저장할 수 있습니다.
2. 이미 불러온 문제를 수정한 뒤 다시 저장하면 기본적으로 **같은 문제를 덮어써서 수정**합니다. 완전히 다른 새 문제를 작성했다면 반드시 **"새 문제로 저장"** 버튼을 눌러 별개의 문제로 저장하세요 (그렇지 않으면 이전 문제를 실수로 덮어쓸 수 있습니다).
3. 상단의 **📚 문제 목록** 버튼을 누르면 저장된 문제들을 검색·태그로 필터링해 볼 수 있습니다. 각 문제는 **불러오기**(편집기로 불러와 이어서 수정)와 **삭제**가 가능합니다.
4. 문제 목록에서 여러 문제를 체크박스로 선택한 뒤 **"선택 항목으로 시험지 만들기"**를 누르면, 선택한 문제들이 번호가 매겨진 하나의 시험지로 합쳐져 편집기에 채워집니다.
5. 문제 데이터는 서버가 아니라 **이 브라우저의 로컬 저장소(localStorage)**에만 저장됩니다. 다른 기기·다른 브라우저와는 공유되지 않으니, 여러 문제를 만들었다면 가끔 **Markdown** 버튼으로 `.md` 파일로도 내보내 백업해 두는 것을 권장합니다.

## 변경 이력

### 2026-09-29 (4)

- **마크다운/수식 라이브러리를 CDN에서 저장소 내부(`vendor/`)로 옮김.** 굵게(`**`), 구분선(`---`) 등 마크다운 서식이 표시되지 않는다는 제보가 있었는데, 원인은 `markdown-it` 라이브러리를 불러오던 CDN(cdnjs.cloudflare.com)이 학교 등 일부 네트워크에서 차단되어 있으면 라이브러리 로딩 자체가 실패해서 마크다운이 전혀 해석되지 않고 원문 그대로 표시되는 것으로 추정됨 (수식은 별도 CDN에서 불러오는 KaTeX라 영향을 받지 않아 정상 동작했을 것). KaTeX·markdown-it 파일을 모두 저장소 안에 내려받아 포함시켜, 이제 외부 CDN에 전혀 의존하지 않고 항상 동일하게 렌더링됩니다.

### 2026-09-29 (3)

- 인쇄·PDF 헤더에 자동으로 붙던 **제목과 날짜 표시를 모두 제거**. 별도 제목 입력창을 두지 않고, 본문 맨 앞에 `# 제목` 형태로 직접 적은 내용이 그대로 인쇄에 반영되도록 단순화함. ((2)에서 파일 이름과 분리해 추가했던 별도 "제목" 입력창은 다시 제거)

### 2026-09-29 (1)

- 앱 안에 **"문제 목록"(문제 은행)** 기능 추가: 여러 문제를 제목·태그와 함께 저장/검색/태그 필터링, 편집기로 다시 불러오기, 선택한 문제들을 모아 시험지로 합치기 (localStorage 기반, 별도 서버 없음)
- **자기 채점용 정답 접기/펼치기** 기능 추가: `<details><summary>정답 및 풀이 보기</summary>...</details>` 문법으로 정답을 감출 수 있고, "정답 모두 펼치기/접기" 버튼과 인쇄 연동(접은 상태로 인쇄 = 학생용, 펼친 상태로 인쇄 = 정답지) 지원
- 마크다운 렌더러에서 raw HTML을 허용하도록 설정(`html:true`) — 위 정답 접기 기능에 필요
